Featured Project

Communication-Aware Distributed MPC for DC Microgrids

A new project concept at the intersection of distributed control, co-simulation, and smart-grid operation.

All Distributed Control Co-Simulation Smart Grids

Project Summary

This project develops a communication-aware distributed Model Predictive Control (MPC) framework together with a real-time software prototype for the coordinated operation of DC microgrids. The proposed approach enables voltage regulation and proportional current sharing among multiple converter-interfaced Distributed Generation Units (DGUs).

The control strategy is implemented in a real-time co-simulation environment, where distributed MPC controllers run in Python and communicate via a P2P Publish/Subscribe architecture, while the primary converter dynamics and PWM-based PI controllers of DC-DC buck converters are simulated in Simulink.

The prototype allows realistic evaluation of control performance, communication latency, and distributed optimization under cyber–physical constraints. The developed platform serves as a control-oriented digital testbed for distributed energy systems, enabling rapid validation of advanced coordination strategies for next-generation DC microgrids.
