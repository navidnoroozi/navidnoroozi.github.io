Featured Project

Data-driven Distributed Intraday Energy Management for 16.7-Hz Railway Power Systems

A two-layer energy-management framework combining centralized day-ahead planning with distributed scenario-based intraday MPC for 16.7-Hz railway power networks.

Distributed Control Smart Grids Railway Power Systems Stochastic MPC Python

Project Summary

This project develops a two-layer energy-management system for 16.7-Hz single-phase railway power networks represented as interconnected control areas. A centralized hourly day-ahead plan is combined with recursive distributed intraday scenario Model Predictive Control (MPC), using forecasts of tractive demand, available regenerative energy and renewable generation together with measurements of wayside-storage energy. The intraday planning problem is formulated as a risk-neutral convex stochastic optimization problem and solved as sparse area-wise quadratic programs coordinated by consensus ADMM.

The accompanying bahnstrom_ems Python proof of concept implements the full workflow: timetable processing and quarter-hour motoring/regenerative-power profiles, energy-price handling, deterministic day-ahead planning, data-driven probabilistic forecasting and scenario generation, distributed intraday optimization, closed-loop state propagation, and KPI/result logging. The software is designed for reproducible numerical studies of distributed energy management in railway power systems.

Featured Project

Communication-Aware Distributed MPC for DC Microgrids

Distributed MPC with finite-step Lyapunov certificates for constrained interconnected systems, experimentally specialized to current sharing and terminal bus-voltage safety in a two-DGU DC microgrid.

Distributed Control Co-Simulation Smart Grids

Project Summary

This project develops a distributed Model Predictive Control (MPC) framework for constrained interconnected nonlinear discrete-time systems using finite-step control Lyapunov functions and finite-step small-gain conditions. At each sampling instant, every subsystem solves one local optimization problem using time-aligned neighbor predictions, optimized state-constraint tightening radii, and a finite-step small-gain terminal inequality. Because communicated neighbor predictions need not coincide with the trajectories generated by future receding-horizon optimizations, the framework introduces shift-compatible constraint margins, a local one-step terminal feasibility test for networks that are affine in the control input, and an analytical bound on the prediction and reoptimization mismatch.

The resulting analysis establishes recursive feasibility, constraint satisfaction, and a practical M-step Lyapunov estimate, with asymptotic convergence when the prediction and reoptimization mismatch bound tends to zero. For constrained linear networks, the required conditions reduce to finite-dimensional matrix, QP, and SOCP tests. The framework is specialized to current sharing and terminal bus-voltage safety under DC/DC converter operating constraints and is evaluated experimentally on a small laboratory-scale two-DGU DC microgrid prototype.

Featured Project

Distributed Hybrid MPC Formation Control for Multi-Robot Systems

A new project concept at the intersection of distributed control, co-simulation, and multi-agent systems.

Distributed Control Co-Simulation Robotics Autonomous Driving

Project Summary

This project delivers an end-to-end software prototype for safe coordination of a team of mobile robots, spanning rigorous theory, simulation, and hardware deployment. On the theoretical side, we develop a distributed hybrid Model Predictive Control (MPC) scheme for multi-agent consensus and formation control under time-varying directed communication, state and input constraints. Formation is recast as stabilization of the agreement set via a geometric viewpoint: building on Moreau's convex-hull invariance condition, we show that enforcing terminal inclusion in local neighbor convex hulls is necessary but not, in general, sufficient for convergence — strict relative-interior placement is additionally required. A lexicographic OCP selection rule resolves this gap and guarantees asymptotic convergence to a safe formation. Formation control reduces to consensus through a shape-compensated coordinate transformation y_i = z_i − c_i, and a five-mode explicit hybrid safety supervisor (modes F / C / O / CO / T) handles inter-agent collision avoidance and obstacle avoidance on top of the nominal MPC law.

On the implementation side, the planning layer is realised as a modular ZMQ-based multi-process Python application (coordinator, per-agent controller, and hybrid safety nodes) operating over a REQ/REP mesh. Theoretical results are validated in a real-time Python ↔ MATLAB/Simulink co-simulation, where Python executes the planning and safety layer while Simulink implements the lower-level unicycle motion-control layer (heading P-controller + speed shaping) for four differential-drive robots. The two layers exchange data each planning step via the matlab.engine API — Python writes velocity references into the MATLAB workspace and reads back odometry, closing the loop through the actual unicycle dynamics. The co-simulation platform is instrumented with structured CSV logging (planning, odometry, hybrid modes, health) for diagnosis and reproducibility. The next step is hardware deployment on a team of four Raspberry Pi 4 / ESP32-based differential-drive robots communicating over WiFi.
